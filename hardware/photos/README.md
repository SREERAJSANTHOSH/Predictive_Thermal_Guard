# Prototype photographs

Add photographs only after the real assembly is wired and powered. Suggested
files:

- `breadboard-overview.jpg` — full prototype with the ESP32, mux, and sensors
  visible
- `sensor-placement.jpg` — sensor positions and the monitored target
- `serial-output.jpg` — optional photograph or screenshot showing detected
  mux channels

Do not substitute a rendered or generated breadboard image for the physical
prototype. In the main README, replace the photo placeholder after adding
`breadboard-overview.jpg`.
